# CutByCut

Бесплатный редактор для Windows: видео, аудио и фото в одном приложении. Построен на Electron.

## Запуск

Нужны Node.js и FFmpeg (`winget install Gyan.FFmpeg`).

```
npm install
npm start
```

Сборка: `npm run pack`.

## Ключи

В репозитории нет ключей. Ключи сервисов (Pixabay, Pexels, Freesound, remove.bg) вводятся в настройках приложения и хранятся только на вашем компьютере.
